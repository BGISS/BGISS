## Featured Project

### [Hydra](https://github.com/BGISS/Hydra) — AI Blue Team Sandbox

An adversarial evasion lab: a local LLM rewrites a benign, ransomware-shaped sample and tries to slip it past two real detectors — YARA (signature) and Falco (behavioral eBPF) — in a closed loop, measuring how each holds up. The sample is intentionally harmless (sandboxed, no network, no persistence) and the point is the measurement, not the exploit: the signature detector falls within a few iterations, the behavioral one doesn't.

`Python` · `Ollama (local LLM)` · `YARA` · `Falco / eBPF` · `Docker`
